# Brody's Home School Portal

Static GitHub Pages starter for Brody's 2026–2027 Grade 7 homeschool year.

Tracks:
- assignments and completion dates
- assessment status, scores, notes, and links
- daily learning logs and minutes
- portfolio/work-sample links
- printable progress summaries
- JSON and CSV exports

Important: this starter stores records in the browser with localStorage. Export the full record regularly.

GitHub Pages:
1. Create a repository.
2. Upload index.html, styles.css, and app.js.
3. Settings -> Pages.
4. Deploy from the main branch, root folder.


## Standards rule
- Massachusetts standards are used only for the initial exit/baseline assessments to establish where prior instruction left off.
- Ongoing instruction is organized around California requirements and standards.
- The Subjects page includes links/sections for California Grades 7–12 areas of study plus Health and Computer Science/Digital Literacy readiness.

## Mathematics Diagnostic
- `math-assessment.html` is a one-time, 68-question diagnostic.
- Questions 1–60 are Massachusetts Grade 6 baseline items.
- Questions 61–68 are California Grade 7 reach probes reported separately from the baseline.
- The student receives no correctness feedback, hints, answer key, running score, or final score.
- Answers may be changed freely until final submission.
- Final submission locks the attempt in that browser.
- A parent archive JSON contains every response plus Massachusetts source standard, California reporting domain/topic/skill, and summaries by domain/topic/skill.
